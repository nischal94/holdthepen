## Eval suites (LLM-touching)

- Tool selection: "what does this question mean?" → explain (not fill); "put my income in" → fill_field.
- Ambiguous: "help me with this section" — acceptable calls documented.
- Mid-chain: staging invalidated by edit → agent re-stages rather than approving.
